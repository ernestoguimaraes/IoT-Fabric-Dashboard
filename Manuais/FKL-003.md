# FKL-003 - Empilhadeira 3

**Manual ficticio, exclusivo para demonstracao. Nao aplicar em maquinas reais.**

Empilhadeira eletrica para demonstrar movimentacao em ciclo longo.

## Parametros sugeridos

| Parametro | Valor | Finalidade |
|---|---|---|
| `mode` | `auto` | Perfil do simulador apos liberacao; nao indica autonomia real. |
| `speed` | 100% | Velocidade relativa de deslocamento; nao representa km/h. |
| `targetTemp` | 55 graus C | Alvo ficticio revisado, abaixo do limite. |
| `tempLimit` | 65 graus C | Disparar alarme de temperatura. |
| `vibLimit` | 1,2 mm/s | Disparar alarme de vibracao. |
| `cycleTime` | 140 s | Duracao da movimentacao simulada. |

## Operacao e ajuste

O cadastro original usa alvo de 66 graus C e limite de 65 graus C. Este manual sugere 55 graus C sem alterar o cadastro. Pause a demonstracao antes de revisar o perfil; 140 s esta dentro da faixa de ate 300 s aceita para empilhadeiras.

## Alerta comum e acao

**Temperatura elevada:** leitura igual ou superior a 65 graus C. Mantenha a movimentacao simulada pausada, registre a leitura e solicite avaliacao ficticia da carga de trabalho e do acionamento eletrico. Nao eleve o limite para aceitar os 66 graus C iniciais. Retome somente apos normalizacao e liberacao do responsavel. Consulte as [regras gerais](README.md).
